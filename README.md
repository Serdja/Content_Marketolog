# Content_Marketolog

🎁 AI-сотрудник «Контент-маркетолог» для Claude Code.

Вы даёте ему любой текст (транскрипцию, статью, пост, заметку) — он выдаёт готовый контент под все соцсети:
рилсы, посты, карусели, статьи.

## Команды

| Команда | Что делает |
|---|---|
| `/reels [текст]` | 6 сценариев Reels |
| `/short-post [текст]` | 3–7 коротких постов |
| `/long-post [текст]` | длинный пост, 2000–3000 знаков |
| `/carousel [текст]` | карусель для Instagram |
| `/article [текст]` | статья |
| `/content [текст]` | всё сразу: анализ → золотые куски → все форматы |

## Установка

### 1. Скилл (для автоматического срабатывания на запросы вида «сделай контент из этого текста»)

```bash
mkdir -p ~/.claude/skills
cd ~/.claude/skills
git clone https://github.com/serdja/content_marketolog.git content-marketolog
```

### 2. Слэш-команды `/reels`, `/short-post`, `/long-post`, `/carousel`, `/article`, `/content`

```bash
mkdir -p ~/.claude/commands
cp ~/.claude/skills/content-marketolog/commands/*.md ~/.claude/commands/
```

(Чтобы команды работали только в конкретном проекте, скопируйте файлы из `commands/` в `.claude/commands/`
внутри этого проекта вместо `~/.claude/commands/`.)

Перезапустите Claude Code. После этого возьмите транскрипцию урока или голосового сообщения и отправьте
`/content [транскрипция]` — получите готовый контент под все платформы.

## Контекст автора

Скилл не хранит данных об авторе. Перед каждым запуском он читает `reference/00-my-context.md`, который ведёт в Obsidian vault (`~/Obsidian`): голос, профиль, запреты. Для проекта добавь `--project tg-leads`. Если vault недоступен, скилл спросит четыре вопроса и пометит текст как черновик.

## Структура репозитория

```
SKILL.md            — описание скилла и общий пайплайн
reference/00-my-context.md — указатель на контекст автора (без личных данных)
reference/           — методология: анализ текста, золотые куски, правила для каждого формата, тон голоса
commands/             — слэш-команды /reels, /short-post, /long-post, /carousel, /article, /content
```
