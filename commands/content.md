## Шаг 1. Анализ

Кратко определи: тема, аудитория, главное обещание/трансформация, тон автора.

## Шаг 2. Золотые куски

Найди 5–10 самостоятельных сильных мыслей (цитата, контринтуитив, кейс, ошибка, фреймворк, цифра, аналогия,
возражение). Выпиши их списком с типом каждой, прежде чем переходить к форматам:

```
Золотые куски:
1. [Тип] — мысль
2. [Тип] — мысль
...
```

## Шаг 3. Форматы

Сделай все форматы ниже. Каждый формат и каждая единица контента внутри него (отдельный Reels/пост/слайд)
должны опираться на свой золотой кусок — не дублируй одну и ту же мысль во всех форматах. Если кусков не
хватает на полный объём — сделай меньше единиц контента, но не выдумывай материал.

**Reels (до 6 сценариев).** Структура: Хук (0–3 сек) → Удержание (3–10 сек) → Тело (10–40 сек, 2–4 шага) →
CTA. 20–60 секунд, разные формулы хуков (вопрос-провокация, неожиданный факт, стоп-сигнал, личное признание,
контраст, список с числом).

```
Reels N — [название]
Источник: [кусок]
Хук: ...
Текст на экране: ...
Голос за кадром: ...
CTA: ...
```

**Короткие посты (3–7 шт).** Хук-строка → раскрытие в 2–4 предложениях → вывод/вопрос. 300–800 знаков,
один пост = одна мысль.

```
Пост N
[текст]
```

**Длинный пост (2000–3000 знаков).** Хук-абзац → контекст/история → 3–5 ключевых пунктов → итог → CTA-вопрос.
Короткие абзацы, без markdown-заголовков.

```
Длинный пост
[текст]
```

**Карусель (6–10 слайдов).** Слайд 1 — обложка-хук, слайды 2…N−1 — один пункт на слайд, последний — итог + CTA.

```
Карусель
Слайд 1 (обложка): ...
Слайд 2: ...
...
Слайд N (финал): ...
```

**Статья (800–1500 слов).** Заголовок → вводный абзац → 3–6 разделов с подзаголовками → заключение → CTA.

```
# [заголовок]
[вводный абзац]
## [подзаголовок]
[текст]
...
## Вывод
[текст]
```

## Общие правила

Не выдумывай факты, цифры, кейсы и цитаты, которых нет в исходнике. Сохраняй характерные слова автора.
Если исходник слишком короткий для полного объёма — сделай меньше материала, но честно, и скажи об этом.

Исходный текст:
$ARGUMENTS
