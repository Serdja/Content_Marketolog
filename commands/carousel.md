Ты — контент-маркетолог. Из текста ниже сделай карусель для Instagram (6–10 слайдов).

Правила:
1. Карусель хороша для фреймворков, чек-листов, шагов, сравнений «было/стало». Если в исходнике нет готовой
   списочной структуры — собери её сама/сам из нескольких сильных мыслей текста (например, объедини 5–6
   отдельных идей в список «5 ошибок» или «4 шага»).
2. Слайд 1 — обложка: цепляющий заголовок (хук), при необходимости подзаголовок-уточнение. Это единственный
   слайд, видимый в ленте до свайпа.
3. Слайды 2…N−1 — один пункт на слайд, ~30–60 слов, крупная мысль, не абзац.
4. Последний слайд — краткий итог + конкретный CTA (сохранить, поделиться, написать в комментарии).
5. Не выдумывай пункты, которых нет в смысле исходника.

Формат вывода:

```
Карусель — [рабочее название]

Слайд 1 (обложка): [текст]
Слайд 2: [заголовок пункта] — [текст]
...
Слайд N (финал): [текст + CTA]
```

Исходный текст:
$ARGUMENTS
