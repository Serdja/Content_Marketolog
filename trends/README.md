# База трендов для рилсов

Цель: копить залетевшие ролики по теме ИИ, автоматизация, big data, аналитика, фиксировать показатели и приёмы,
чтобы потом повторять их на своей теме. Новое придумываем только после того, как база показала, что работает.

## Инструкция для агента (каждый запуск)

1. Найти залетевшие ролики по теме: Instagram Reels, TikTok, YouTube Shorts. Берём только те, где видно показатели
   (просмотры, аутлайер-скор или сравнение с обычными результатами автора).
2. Для каждого ролика записать в `library.md` одну строку в таблице и карточку ниже таблицы:
   - дата записи, платформа, ссылка, автор (handle), просмотры, аутлайер-скор, длительность;
   - хук (первые 3 секунды, дословно или коротко), структура по блокам, тип ролика из `reference/09-reel-types.md`;
   - что делает ролик залетевшим (одной фразой, гипотеза помечена как гипотеза);
   - идея адаптации на свою тему (без копирования текста и кадров).
3. Ролики без показателей не записывать. Паттерн считать подтверждённым, если его используют минимум 2 залетевших ролика.
4. Перед генерацией 7 рилсов агент читает `library.md` и `reference/09-reel-types.md` и подбирает 7 разных типов.
5. Личность владельца появляется в роликах по правилу типа (см. `09-reel-types.md`), а не в каждом ролике.

## Что не делаем

- Не копируем чужой текст, озвучку, кадры и музыку. Берём только структуру и приём.
- Не записываем в библиотеку личные данные авторов сверх публичного handle и ссылки.
- Не выдаём гипотезу за факт: в карточке «почему залетел» помечаем как гипотезу.

## Файлы

- `library.md` — накопленная библиотека залетевших роликов.
- `reference/09-reel-types.md` — типы рилсов, их задача и место владельца в кадре.
- `reference/08-trend-reels.md` — правило: 7 рилсов, основа — тренды.
