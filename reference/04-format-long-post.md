# Формат: длинный пост (2000–3000 знаков)

## Принцип

Длинный пост — это не статья, сжатая в один пост, а одна большая мысль, раскрытая через историю/контекст и
несколько ключевых пунктов. Должен держать внимание абзац за абзацем — каждый абзац обязан давать причину
читать следующий.

## Структура

1. **Хук-абзац** — 1–3 предложения, цепляющие с первой строки (та же логика, что и хук в Reels).
2. **Контекст/история** — личный опыт автора или конкретный кейс, который подводит к главной мысли. Это
   удерживает внимание лучше, чем сразу выданный тезис.
3. **Ключевые пункты (3–5)** — раскрытие главной мысли по частям. Каждый пункт — отдельный короткий блок,
   можно с цифрой или эмодзи-маркером для визуального разделения.
4. **Итог** — главная мысль одной-двумя фразами, без повтора всего сказанного.
5. **CTA-вопрос** — вопрос аудитории, который провоцирует комментарии, либо конкретное действие.

## Форматирование (важно для соцсетей)

- Абзацы по 2–3 строки максимум — стены текста не дочитывают.
- Пустая строка между абзацами.
- Не используй заголовки markdown (#, ##) — в постах соцсетей они не рендерятся как заголовки, используй
  эмодзи-маркеры или цифры для визуального деления.

## Формат вывода

```
Длинный пост
[Готовый текст поста, 2000–3000 знаков]
```
