# Формат: карусель для Instagram

## Принцип

Карусель хороша для фреймворков, чек-листов, пошаговых инструкций и сравнений «было/стало» — структур,
которые естественно разбиваются на пункты. Если в исходнике нет такой структуры, сначала сформируй её
из золотых кусков (например, объедини 5–6 отдельных мыслей в один список «5 ошибок» или «4 шага»).

## Структура

- **Слайд 1 — обложка**: цепляющий заголовок (хук) + при необходимости подзаголовок-уточнение. Это
  единственный слайд, который виден в ленте до свайпа — вся сила хука здесь.
- **Слайды 2…N−1 — содержание**: один пункт на слайд. Текста немного (~30–60 слов), крупная мысль, не абзац.
  Если это список/шаги — нумеруй слайды соответствующим пунктом.
- **Последний слайд — итог + CTA**: краткое резюме (необязательно) + конкретное действие: сохранить,
  поделиться, написать в комментарии, подписаться.

Общее количество слайдов: 6–10.

## Формат вывода

```
Карусель — [рабочее название]

Слайд 1 (обложка): [текст]
Слайд 2: [заголовок пункта] — [текст]
Слайд 3: [заголовок пункта] — [текст]
...
Слайд N (финал): [текст + CTA]
```
