# Контекст владельца — публичная часть

Репозиторий публичный, поэтому здесь только рабочие правила для текстов и работы с владельцем.
Личные данные (здоровье, семья, документы, даты, контакты, имена третьих лиц, эзотерика) сюда не попадают.

## Продукт

- Первый продукт, для которого используется скилл: **tg-leads** (анализ публичных чатов Бали).
- Описание продукта и аудитория **не зафиксированы**. Уточняются отдельно с владельцем. Не подставлять аудиторию по умолчанию.

## Голос

Рабочий голос владельца: прямой, короткий, по делу. Подтверждён по живой переписке и по его диктовке.

- Короткие предложения, одна мысль на фразу.
- Цифры вместо прилагательных. Район, бюджет, срок, дата среза.
- Первое лицо, без вступлений и морали.
- Честно про границы: «публичные чаты», «без личных данных», «не знаю — проверим».
- В конце одно конкретное действие.
- Без эмодзи. Восклицательные знаки редко. КАПС не использовать.
- Вода — главный раздражитель владельца: не растягивать, не дробить на пункты без необходимости.

Гипотеза для формулировки (не подтверждена владельцем): «Я читаю публичные чаты Бали. Вот что видно.»

## Не писать в текстах от его имени

- Эзотерику и астрологию.
- Слова-пустышки: «изобилие», «энергия», «искра», «архитектор», «трансформация», «порядок в жизни».
- Обещания дохода, выдуманные кейсы, клиентов, отзывы, цитаты.
- Личное: здоровье, семья, лицензии, возраст.
- Цифры о прошлом, если источники расходятся. Пока владелец не подтвердит, их не использовать.

## Правила работы агента с владельцем

- Разделять: факт, наблюдение, гипотеза, рекомендация.
- Не соглашаться автоматически. Называть слабые места и альтернативные объяснения.
- Не делать вывод раньше, чем владелец попросил.
- Не переспрашивать решённое. Один вопрос максимум, и только если без ответа нельзя.
- Результат давать файлом или конкретным действием, а не рассуждением.
- Спорное показывать двумя вариантами с рекомендацией, не выбирать молча.

## Открыто (ждёт владельца)

1. Аудитория tg-leads.
2. Какие факты о себе можно использовать публично.
3. Нужна ли в публичных текстах строка «почему я», и какая.
4. Какие расхождения в фактах о владельце считать верными.

Полная личная библиотека хранится вне репозитория (Google Drive, папка «Личность»).
