# Формат: Reels (6 сценариев)

## Принцип

6 сценариев — это 6 **разных** золотых кусков, поданных как отдельные ролики, а не один и тот же кусок,
нарезанный шесть раз. Каждый ролик должен жить самостоятельно — зритель, который видел только один из
шести, должен получить законченную мысль.

## Структура одного сценария

1. **Хук (0–3 сек)** — первая фраза останавливает скролл. Без неё досматривать не будут.
2. **Удержание (3–10 сек)** — обещание: что зритель узнает/получит, если досмотрит.
3. **Тело (10–40 сек)** — одна идея, разложенная на 2–4 конкретных шага, примера или довода.
4. **Призыв к действию (последние 3–5 сек)** — конкретное действие: написать в комментарии, сохранить,
   переслать, перейти. Без обтекаемого «подписывайся, если понравилось».

Общая длина ролика: 20–60 секунд. Длиннее — только если материал реально требует (кейс с подробностями).

## Формулы хуков (используй разные для 6 роликов, не повторяй одну формулу шесть раз)

- Вопрос-провокация: «Ты тоже думаешь, что Х?»
- Неожиданный факт: «90% людей делают Х неправильно — вот почему»
- Стоп-сигнал: «Если ты делаешь Х — немедленно остановись»
- Личное признание: «Я три года делал Х, пока не понял, что...»
- Контраст: «Все говорят делать X. Делай наоборот»
- Список с числом: «3 ошибки, которые убивают твой Y»

## Формат вывода для каждого сценария

```
Reels N/6 — [рабочее название, 3–6 слов]
Источник: [какой золотой кусок лёг в основу]

Хук (0–3 сек): ...
Текст на экране: ...
Голос за кадром:
  - [блок 1]
  - [блок 2]
  - [блок 3]
CTA: ...
```

«Текст на экране» — это субтитры/оверлеи, которые удерживают внимание у тех, кто смотрит без звука; они
короче, чем «голос за кадром», и выделяют только ключевые слова, а не дублируют речь целиком.
