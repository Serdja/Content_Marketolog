# Формат: статья

## Принцип

Статья — единственный формат, где можно дать материалу развернуться полностью: контекст, аргументация,
примеры, нюансы. Но это не значит «пересказать исходник подробнее» — структура всё равно нужна, иначе
читатель уйдёт после первого абзаца.

## Структура

1. **Заголовок** — конкретный, обещающий результат или отвечающий на вопрос аудитории. Избегай общих
   формулировок («Про маркетинг») в пользу конкретных («Почему 90% контент-планов не работают»).
2. **Вводный абзац** — обозначает проблему или обещание статьи, даёт читателю причину читать дальше.
3. **Основная часть (3–6 разделов с подзаголовками)** — каждый раздел раскрывает одну часть темы, с
   примерами/кейсами из исходника, без воды между разделами.
4. **Заключение** — практический вывод: что читателю делать с этой информацией.
5. **CTA** — естественное завершение: вопрос, приглашение к действию, ссылка на следующий шаг (если применимо).

## Параметры

- Объём: 800–1500 слов.
- Подзаголовки — конкретные, а не «Введение»/«Заключение» (используй формулировки по теме раздела).
- Если в источнике есть ключевая фраза/тема, которую логично использовать в заголовке и подзаголовках для
  SEO — используй её, но не в ущерб естественности текста.

## Формат вывода

```
# [Заголовок статьи]

[Вводный абзац]

## [Подзаголовок раздела 1]
[Текст]

## [Подзаголовок раздела 2]
[Текст]

...

## Вывод
[Практическое заключение + CTA]
```
