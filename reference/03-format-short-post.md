# Формат: короткие посты (3–7 штук)

## Принцип

Каждый короткий пост = один золотой кусок = одна мысль. Не пытайся впихнуть в один пост несколько идей —
это ослабляет каждую из них.

## Структура

1. **Хук-строка** — первая строка, которая видна без «читать дальше»/разворачивания. Должна работать как
   самостоятельный заголовок.
2. **Раскрытие мысли** — 2–4 коротких предложения, разворачивающих хук: довод, пример, объяснение «почему».
3. **Вывод или вопрос** — итоговая мысль одной строкой, либо вопрос для комментариев, если цель — вовлечение.

## Параметры

- Объём: 300–800 знаков на пост.
- Короткие абзацы (1–2 предложения), разделённые пустой строкой — это мобильное чтение, не книга.
- Без списков из 5+ пунктов — короткий пост держится на одной мысли, а не на чек-листе (для чек-листа есть карусель).

## Формат вывода

```
Пост N/M
[Текст поста целиком, готовый к публикации]
```

Сделай 3–7 постов в зависимости от того, сколько в исходнике реально сильных самостоятельных мыслей —
не растягивай слабый материал до 7 ради количества.
